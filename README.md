# power-bi-dashboard
📊 Ecommerce Sales Dashboard - Power BI
📌 Project Overview

The Ecommerce Sales Dashboard is an interactive Power BI dashboard developed to analyze and visualize ecommerce sales data. This dashboard provides business insights into sales performance, customer behavior, product profitability, regional sales distribution, and overall business performance through interactive visualizations.

The objective of this project is to help businesses monitor key performance indicators (KPIs), identify top-performing products, understand regional sales trends, and support data-driven decision making.

🚀 Features
Interactive Power BI Dashboard
KPI Cards for Business Performance
Product-wise Profit Analysis
Region-wise Sales Analysis
Customer-wise Sales Distribution
Product-wise Revenue Analysis
Order Quantity Analysis
Average Order Value (AOV)
Clean Dark Theme UI
Interactive Charts & Filters
